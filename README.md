# 영끌말판

지방 원룸에서 시작해 경기도, 서울, 강남 아파트까지 이사하는 1인용 주사위 말판 웹게임입니다.

- 주사위 한 번 = 3개월. 월급, 생활비, 대출 이자, 집값 변동이 매 분기 반영됩니다.
- 말판 끝 이사 심사에서 지금 집을 팔고 대출을 끼워 다음 지역 집을 사면 이사합니다.
- 호재·악재·뉴스(금리, 세법개정안→확정, 선거 후 정책), 투자 칸의 "집값 그래프 타기" 미니게임.
- 집값은 국토교통부 아파트 매매 실거래가(2026년 7~9월 계약분)의 지역 평균 평당가 × 전용면적(59㎡, 84㎡)으로 계산한 추정치입니다. 단지 이름과 사건은 모두 가상입니다.

빌드 없이 `index.html`을 열면 실행됩니다.
